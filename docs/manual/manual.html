1. Conhecendo o sistema

1.1 O que o sistema faz

O SuaLojaAqui junta duas coisas num só sistema:

  • Frente de caixa (PDV): o operador bipa os produtos, recebe o pagamento (dinheiro, PIX, cartão — até misturados na mesma venda), o sistema calcula o troco e imprime o comprovante.
  • Controle de estoque: cada venda baixa o estoque sozinha; entradas de mercadoria, perdas e ajustes ficam registrados; o sistema avisa quando é hora de comprar.

Ele roda no navegador (Edge, Chrome), num computador da loja que funciona como "servidor". Os outros caixas, o computador do escritório, tablets e celulares da mesma rede acessam esse computador.

⚠️ Sistema NÃO FISCAL Esta versão não emite NFC-e, SAT nem nota fiscal e não se comunica com a SEFAZ. Todo comprovante sai com a frase "Documento Não Fiscal — Sem Valor Fiscal". Se a sua loja é obrigada a emitir cupom fiscal, use um emissor fiscal à parte.

1.2 Quem usa o sistema (perfis)

Cada funcionário tem o próprio usuário. O perfil define o que ele pode fazer:

PerfilO que faz
Operador de caixaAbre e fecha o caixa, vende, consulta produtos e reimprime comprovantes do turno. Ao entrar, cai direto na tela do caixa.
GerenteTudo do operador, mais: dá descontos sem limite, cancela vendas, faz sangria/suprimento, autoriza essas ações para o operador e vê os relatórios de vendas e caixas.
EstoquistaCadastra produtos e preços, registra entradas e saídas, cuida das solicitações de pedido e dos relatórios de estoque.
AdministradorAcesso total: usuários, configurações da loja, ajustes de estoque, lixeira e auditoria.

2. Instalação e como ligar o sistema

Este capítulo é para quem vai instalar o sistema no computador principal da loja. Faz-se uma vez só.

2.1 O que você precisa

ItemDetalhe
Computador principalWindows 10 ou 11, 4 GB de memória ou mais, 2 GB livres no disco. Ele precisa ficar ligado enquanto a loja usa o sistema.
Node.jsVersão 22 ou mais nova (LTS). Baixe em https://nodejs.org e instale clicando em "Avançar" até o fim.
Os arquivos do sistemaA pasta do projeto (por download do GitHub ou cópia). Não coloque o banco de dados dentro do OneDrive — o sistema já guarda os dados fora dele, em %LOCALAPPDATA%.
NavegadorMicrosoft Edge ou Google Chrome atualizados.
OpcionalLeitor de código de barras USB (funciona como teclado, sem configuração), impressora térmica e gaveta de dinheiro.

Não é preciso instalar banco de dados: o PostgreSQL já vem junto com o sistema.

2.2 Instalação passo a passo

  1. Instale o Node.js (veja acima). Para conferir, abra o Prompt de Comando (tecla Windows, digite cmd, Enter) e rode node -v. Deve aparecer algo como v24.x.x.
  2. Abra a pasta do sistema no Prompt de Comando. Exemplo: 
    cd "C:\Users\SEU-USUARIO\Documentos\projeto"
  3. Rode a instalação (demora alguns minutos na primeira vez): 
    npm.cmd run setup
    Ela instala tudo, cria o arquivo de configuração apps\api\.env com senhas aleatórias, cria o banco de dados e o usuário admin. No final aparece a senha provisória do admin — anote.
  4. (Opcional) Carregue produtos de exemplo para treinar: 
    npm.cmd run db:demo -w @vl/api
  5. Gere a versão de uso do sistema: 
    npm.cmd run build
  6. Ligue o sistema: dê dois cliques no arquivo iniciar-sistema.bat da pasta. Uma janela preta chamada SuaLojaAqui abre e, em seguida, o navegador em http://localhost:3000.
💡 Por que "npm.cmd" e não "npm"? No PowerShell do Windows, o comando npm pode dar o erro "a execução de scripts foi desabilitada neste sistema". Escrever npm.cmd evita o problema. Se preferir liberar o npm de vez, rode uma vez no PowerShell: 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
e responda S. Usar o Prompt de Comando (cmd) em vez do PowerShell também resolve.

2.3 Ligar e desligar no dia a dia

AçãoComo fazer
LigarDois cliques em iniciar-sistema.bat. Aguarde o navegador abrir (uns 10 segundos).
DesligarFeche a janela preta SuaLojaAqui. O banco de dados é desligado com segurança.
Abrir de novo no navegadorDigite http://localhost:3000 (ou use o favorito). Dica: crie um atalho na área de trabalho.
Ligar junto com o WindowsTecla Windows + R, digite shell:startup, Enter, e coloque nessa pasta um atalho para o iniciar-sistema.bat.
⚠️ Não feche a janela preta durante o expediente Ela é o "motor" do sistema. Se for fechada, os caixas dos outros computadores perdem a conexão (o caixa continua vendendo offline, mas o ideal é religar logo).

2.4 Acessar de outros computadores, tablets e celulares

  1. No computador principal, descubra o IP: abra o cmd e rode ipconfig. Anote o "Endereço IPv4" da rede da loja (ex.: 192.168.0.9).
  2. No outro aparelho (na mesma rede/Wi-Fi), abra o navegador em http://192.168.0.9:3000.
  3. Se não abrir, libere a porta 3000 no Firewall do Windows do computador principal (Firewall → Configurações avançadas → Regras de entrada → Nova regra → Porta → TCP 3000 → Permitir).
  4. No navegador do aparelho, use "Instalar aplicativo" / "Adicionar à tela inicial" para abrir como um aplicativo.
💡 IP fixo Peça para quem cuida da rede (ou configure no roteador) um IP fixo para o computador principal. Assim o endereço dos caixas nunca muda.

2.5 Erros comuns na instalação

Mensagem / sintomaSolução
"a execução de scripts foi desabilitada"Use npm.cmd no lugar de npm (veja a dica do item 2.2).
"Node.js não encontrado"Instale o Node.js e feche e abra o Prompt de Comando.
P1000: Authentication failed (senha do banco)O arquivo apps\api\.env tem uma senha diferente da do banco que já existe no computador. Use o .env antigo ou, para começar com um banco novo, preencha DB_DATA_DIR no .env com uma pasta nova (ex.: C:/Users/SEU-USUARIO/AppData/Local/sualoja/pgdata) e rode de novo npm.cmd run db:deploy -w @vl/api e npm.cmd run db:seed -w @vl/api.
"a porta 3000 já está em uso"O sistema já está ligado em outra janela. Feche a janela antiga ou use a que já está aberta.
Página não abre em localhost:3000Confira se a janela preta está aberta e sem erro em vermelho. Espere 20 segundos e atualize (F5 fora do caixa).
Esqueci a senha do admin inicialEla está no arquivo apps\api\.env, na linha ADMIN_INITIAL_PASSWORD (só vale para o primeiro acesso).

3. Primeiro acesso e configuração da loja

3.1 Entrar pela primeira vez

  1. Abra http://localhost:3000, digite o usuário admin e a senha provisória anotada na instalação.
  2. O sistema pede para criar uma senha pessoal (mínimo de 8 caracteres, com letras e números).
  3. Em Meu perfil (clique no seu nome, embaixo do menu), crie o seu PIN. Ele é pedido em operações sensíveis e permite autorizar ações no caixa.

3.2 Identidade da loja (nome, logotipo e cores)

Menu Administração → Configurações → Identidade da loja:

  • Nome da loja e slogan: aparecem no menu, no login, na aba do navegador e nos comprovantes.
  • Logotipo: imagem PNG, JPEG, WebP ou SVG de até 150 KB. Prefira fundo transparente e formato quadrado.
  • Cor principal: clique no quadrado colorido ou digite o código (ex.: #0F766E). Todo o sistema se adapta à cor.
  • Tema padrão: claro, escuro ou "seguir o sistema operacional". Cada computador pode trocar no botão ☀️/🌙.
  • CNPJ/CPF, endereço, telefone e cabeçalho extra: impressos no topo do comprovante.
  • Mensagem no rodapé: ex.: "Obrigado pela preferência!".

Clique em Salvar alterações no topo da página.

3.3 Impressora

Ainda em Configurações, no quadro Impressão, escolha o papel (bobina 80 mm, 58 mm ou A4) e a conexão. Depois de salvar, use Imprimir página de teste. Os detalhes de cada tipo de impressora estão no capítulo 9.

3.4 Regras do caixa

ConfiguraçãoPara que serve
Desconto máximo do operador sem autorização (%)Até esse percentual, o operador dá desconto sozinho. Acima, um gerente precisa autorizar com o PIN. Use 0 para exigir autorização em qualquer desconto.
Bloquear venda de item sem estoqueDesligado (padrão): o caixa vende e só avisa que o estoque está zerado — afinal, o produto está na mão do cliente. Ligado: o caixa não deixa vender.
Segurança: PINEscolha quais operações de estoque pedem o PIN do funcionário.

3.5 Cadastrar os funcionários

Menu Administração → Usuários → Novo usuário. Informe nome, login, perfil, uma senha provisória e o PIN. No primeiro acesso, o funcionário troca a senha.

💡 Todo operador e gerente deve ter PIN O PIN é usado para trocar de operador no caixa e, no caso dos gerentes, para autorizar descontos, cancelamentos e sangrias.

4. Produtos e categorias

4.1 Categorias

Menu Estoque → Categorias. O sistema já vem com categorias de mercadinho e padaria; crie, renomeie ou exclua conforme a sua loja. São dois níveis: categoria (ex.: Bebidas) e subcategoria (ex.: Refrigerantes).

4.2 Cadastrar um produto

Menu Estoque → Produtos → Novo produto:

CampoComo preencher
NomeComo o cliente conhece o produto, com marca e tamanho. Ex.: Arroz Tio João Tipo 1 5kg.
SKUCódigo interno, sem espaços. Ex.: ARROZ-TJ-5KG. Também serve para vender no caixa.
Código de barras (EAN)Clique no campo e bipe a embalagem. Produtos sem código (pão, frios) podem ficar sem — vendem pelo SKU ou pelo nome.
Categoria e unidadeA unidade define como o produto é vendido: UN, KG (por peso), L, CX, PCT...
Preço de vendaO valor cobrado no caixa. Sem preço o produto não pode ser vendido no caixa.
Preço de custoQuanto você paga. Usado para calcular a margem nos relatórios.
Estoque inicialQuantidade que já existe na loja hoje (só no cadastro).

Controlar consumo e reposição (opcional)

No fim do formulário há o interruptor "Controlar consumo e reposição":

  • Ligado (padrão): informe o consumo médio por dia, o consumo máximo por dia e o prazo de entrega do fornecedor. O sistema calcula o ponto de pedido e, quando o saldo chegar nele, cria sozinho uma solicitação de pedido para a gestão.
  • Desligado: para itens que você não repõe por previsão (sacolas, itens de ocasião, produtos sazonais). O produto continua com estoque e preço normais, só não gera pedido automático.
💡 Como estimar o consumo Consumo médio: quanto sai num dia normal. Consumo máximo: quanto sai num dia muito movimentado. Exemplo do pão de forma: média 20, máximo 30, entrega em 3 dias → ponto de pedido = 20 × 3 + (30 − 20) × 3 = 90 unidades.

4.3 Consultar, editar e excluir

  • Na lista, use a busca (nome, SKU ou código) e as abas Precisam de atenção, Sem estoque, Críticos, Repor, Normais.
  • Clique no produto para ver o detalhe e o histórico de movimentações. O ícone de lápis edita.
  • A lixeira guarda produtos excluídos por 15 dias (configurável). Produtos que já foram vendidos nunca são apagados de vez — o histórico de vendas é preservado.
💡 Situação do estoque (cores) 🔴 Sem estoque (saldo zero) · 🟠 Crítico (abaixo do estoque de segurança) · 🟡 Repor (chegou ao ponto de pedido) · 🟢 Normal.

5. Frente de caixa (operador)

A frente de caixa ocupa a tela inteira e funciona toda pelo teclado (as teclas aparecem nos botões, que também podem ser tocados em telas touch). O operador de caixa entra direto nela; os demais perfis acessam pelo menu Operação → Frente de caixa.

5.1 Abrir o caixa

  1. Confira o nome do terminal (ex.: Caixa 01). Cada computador de caixa deve ter um nome diferente; ele fica salvo no computador.
  2. Conte o dinheiro de troco colocado na gaveta e digite em Troco inicial.
  3. Clique em Abrir caixa.

5.2 Registrar uma venda

  1. Bipe o produto. Ele entra no cupom na hora, com um bipe curto. Bipar o mesmo produto de novo soma a quantidade.
  2. Produto sem código: digite parte do nome ou o SKU, escolha com as setas ↑ ↓ e tecle Enter.
  3. Várias unidades de uma vez: digite a quantidade, um asterisco e o código: 3*7891234567890 ou 3*AGUA-500.
  4. Quando acabar, tecle F5 (Finalizar venda).
⚠️ Avisos ao bipar "Produto sem preço de venda": o item não tem preço cadastrado — chame o administrador. "Estoque pode estar desatualizado": o sistema registra saldo zerado; a venda continua, mas avise o estoquista.

5.3 Quantidade, peso e remoção de itens

  • Selecionar um item: clique nele ou use ↑ ↓.
  • Mudar a quantidade: F2, ou + / −. Produtos por peso aceitam decimais: 0,455 kg.
  • Remover o item selecionado: Del. A remoção fica registrada na auditoria.
  • Cancelar a venda inteira: Esc e confirme. Também fica registrado.

5.4 Descontos e autorização do gerente

  • F3: desconto no item selecionado. F4: desconto no total da venda.
  • Escolha Percentual (%) ou Valor (R$) e digite. A prévia mostra o valor do desconto.
  • Se o desconto passar do limite do operador, abre a janela Autorização do supervisor: o gerente digita o próprio usuário e PIN ali mesmo, sem trocar de operador.

5.5 Pagamento e troco

  1. Na janela de pagamento, escolha a forma: F1 Dinheiro, F2 PIX, F3 Crédito, F4 Débito.
  2. Digite o valor e tecle Enter para lançar. O sistema já sugere o valor que falta.
  3. Para misturar formas (ex.: R$ 20 no PIX + o resto em dinheiro), lance uma, depois a outra.
  4. No dinheiro, use os botões de notas (R$ 50, R$ 100...) ou digite o valor entregue. O troco aparece em verde.
  5. Quando o pagamento fechar, tecle F5 (ou Enter com o campo vazio) para confirmar.
💡 Troco só sai do dinheiro PIX e cartão não podem passar do valor que falta. Se o cliente pagar parte no cartão, o troco é calculado apenas sobre o dinheiro entregue.

5.6 Comprovante, PDF e orçamento

Ao confirmar, aparece Venda concluída com o número da venda e o troco em destaque. Escolha Imprimir ou PDF, e Esc para a próxima venda. Se a impressão automática estiver ligada nas configurações, o comprovante sai sozinho.

Orçamento (F8): com itens no cupom, gera um orçamento em A4 para imprimir ou em PDF para enviar ao cliente. Não é venda e não baixa estoque. Depois, cancele o cupom com Esc ou finalize a venda se o cliente fechar negócio.

5.7 Sangria e suprimento (F6)

  • Sangria: retirar dinheiro da gaveta (ex.: levar ao cofre quando acumula muito).
  • Suprimento: colocar dinheiro na gaveta (ex.: mais troco).
  • Informe o valor e a justificativa (obrigatória). O operador precisa da autorização de um gerente. Sai um comprovante para assinatura.
  • A sangria não pode ser maior que o dinheiro que deveria estar na gaveta.

5.8 Reimprimir e cancelar vendas (F7)

F7 mostra as vendas do caixa aberto. Clique numa venda para ver os itens e:

  • Reimprimir: sai a "2ª via" (fica registrado na auditoria).
  • PDF: gera o comprovante em arquivo (ex.: para enviar por WhatsApp).
  • Cancelar venda: informe o motivo. Os produtos voltam ao estoque automaticamente. Operador precisa da autorização do gerente. Só é possível cancelar vendas do caixa que ainda está aberto.

5.9 Trocar de operador (F9)

Na troca de turno ou no intervalo, o próximo operador digita o usuário e o PIN. O caixa continua aberto; as vendas seguintes ficam no nome do novo operador. A troca só é permitida com o cupom vazio.

5.10 Fechar o caixa (F10)

  1. Com o cupom vazio, tecle F10. O sistema mostra o resumo: vendas, totais por forma de pagamento, troco inicial, sangrias, suprimentos e o dinheiro esperado na gaveta.
  2. Conte o dinheiro da gaveta e digite em "Dinheiro contado".
  3. O sistema mostra se o caixa confere, tem falta (vermelho) ou sobra (amarelo). Escreva uma observação, se precisar.
  4. Clique em Fechar caixa e imprimir. O relatório de fechamento sai para assinatura.
⚠️ Vendas pendentes de envio Se houve vendas sem internet que ainda não foram enviadas, o fechamento fica bloqueado até elas sincronizarem. Veja o próximo item.

5.11 Vendendo sem internet

Se a rede cair (ou o computador principal ficar fora do ar), o caixa continua vendendo: o rodapé mostra "Offline — vendendo neste computador" e cada venda é guardada no próprio computador do caixa, com comprovante impresso normalmente (marcado "OFFLINE", o número sai depois).

Quando a conexão volta, as vendas são enviadas sozinhas, sem duplicar, e o estoque é baixado. Você pode forçar o envio clicando em "N venda(s) aguardando envio" no rodapé.

⚠️ O que precisa de conexão Abrir e fechar o caixa, sangria/suprimento, cancelar vendas e a autorização do gerente para descontos acima do limite. Os preços usados offline são os últimos salvos no computador.

6. Estoque

As vendas do caixa já baixam o estoque sozinhas. As telas deste capítulo são para o que não passa pelo caixa.

6.1 Registrar entrada

Menu Operação → Registrar entrada. Escolha o tipo (Pedido recebido ou Retorno ao estoque), bipe o produto, informe a quantidade (e a nota/fornecedor na observação) e confirme. Pode pedir o seu PIN.

Registro rápido: com a opção ligada, cada bipagem registra 1 unidade na hora — útil para conferir uma caixa item a item.

6.2 Registrar saída (perdas e avarias)

Menu Operação → Registrar saída, tipo Perda / quebra / vencimento. Use para produtos estragados, quebrados ou vencidos. Vendas não devem ser lançadas aqui — elas passam pelo caixa.

⚠️ Ajustes de inventário Os tipos Ajuste (entrada) e Ajuste (saída) — usados após contar o estoque — só aparecem para o administrador.

6.3 Movimentações

Menu Estoque → Movimentações: histórico completo de entradas e saídas, com filtros por tipo, direção e período. As vendas aparecem como Venda e os cancelamentos como Estorno de venda cancelada.

6.4 Reposição e solicitações de pedido

Quando um produto com reposição ligada chega ao ponto de pedido, o sistema cria uma solicitação com a quantidade sugerida. Em Estoque → Solicitações de pedido, a gestão acompanha o fluxo:

Pendente → Pedido feito (pedido enviado ao fornecedor) → Recebido (registre também a entrada da mercadoria). Também é possível criar solicitações manuais e imprimir a lista para o fornecedor.

6.5 Relatórios de estoque

Menu Estoque → Relatórios: movimentação por produto no período, estoque parado (sem saída) e rupturas (sem saldo). Exporta para Excel (CSV) e imprime.

6.6 Lixeira

Produtos excluídos ficam na lixeira pelo prazo configurado (padrão 15 dias) e podem ser restaurados. Depois disso são apagados — exceto os que têm vendas, que ficam guardados para sempre.

7. Gerência: vendas e caixas

7.1 Relatório de vendas

Menu Vendas → Vendas. Escolha o período (Hoje, 7 dias, 30 dias ou datas personalizadas) para ver:

  • Total vendido, número de vendas e ticket médio;
  • Descontos concedidos e margem bruta (venda − custo, se o custo estiver cadastrado);
  • Valores por forma de pagamento (dinheiro já sem o troco);
  • Produtos mais vendidos e vendas por operador.

Mais abaixo fica a lista de vendas: pesquise pelo número do comprovante ou filtre canceladas. Clique numa venda para reimprimir, gerar PDF ou cancelar. O botão Exportar CSV abre no Excel.

7.2 Caixas

Menu Vendas → Caixas: todos os turnos, com quem abriu e fechou, o dinheiro esperado, o contado e a diferença (falta em vermelho, sobra em amarelo). Reimprima ou baixe em PDF o relatório de qualquer fechamento.

7.3 Painel

A tela inicial mostra as vendas de hoje (para gerente e administrador), os alertas de reposição e as últimas movimentações.

8. Administração

8.1 Usuários

Menu Administração → Usuários. Pelo menu "⋯" de cada usuário: editar (nome e perfil), redefinir senha (provisória, trocada no próximo acesso), redefinir PIN e desativar.

  • Funcionário que saiu: desative (não exclua). Ele é desconectado na hora e o histórico continua no nome dele.
  • Após 5 senhas ou PINs errados, a conta é bloqueada por 15 minutos.
  • O sistema exige sempre pelo menos um administrador ativo.

8.2 Auditoria

Menu Administração → Auditoria: registro de quem fez o quê e quando — logins, vendas, descontos (e quem autorizou), itens removidos do cupom, cupons cancelados, cancelamentos de venda, sangrias, abertura de gaveta, reimpressões, cadastros, exclusões e mudanças de configuração.

8.3 Boas práticas de segurança

  • Cada pessoa usa o próprio usuário — nunca compartilhe senha ou PIN.
  • Ao sair do computador, clique em Sair (embaixo do menu).
  • Dê o perfil de Gerente só a quem pode autorizar descontos e cancelamentos.
  • Confira a auditoria e as diferenças de caixa com frequência.
  • O arquivo apps\api\.env contém as senhas internas do sistema: não envie a ninguém e não coloque em pastas compartilhadas.

8.4 Backup (cópia de segurança)

Os dados ficam no computador principal, na pasta indicada em DB_DATA_DIR no arquivo .env (padrão: %LOCALAPPDATA%\vl-estoque\pgdata).

  • Para copiar a pasta do banco com segurança, desligue o sistema (feche a janela preta) antes e copie a pasta inteira para um pendrive ou HD externo.
  • Faça a cópia pelo menos uma vez por semana e guarde fora da loja.
  • Guarde também uma cópia do arquivo apps\api\.env (sem ele, o banco copiado não abre).
❗ Nunca coloque a pasta do banco dentro do OneDrive, Google Drive ou Dropbox A sincronização desses programas pode corromper o banco enquanto o sistema está ligado. Copie para lá apenas o backup, com o sistema desligado.

9. Impressoras

O sistema imprime comprovante de venda, orçamento, sangria/suprimento e fechamento de caixa. Configure em Configurações → Impressão.

9.1 Impressora térmica USB ou serial (mais comum)

  1. Instale o driver do fabricante (Epson, Elgin, Bematech, Daruma, Tanca...) e confira se a impressora aparece em Impressoras e scanners do Windows. Imprima uma página de teste pelo Windows.
  2. No sistema, escolha Papel: Bobina térmica 80 mm (ou 58 mm) e Conexão: Impressora do Windows.
  3. Na primeira impressão, escolha a impressora térmica na janela do navegador, ajuste Margens: nenhuma e desmarque Cabeçalhos e rodapés. O navegador lembra a escolha.
💡 Imprimir sem a janela de confirmação Crie um atalho na área de trabalho com o destino: 
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk-printing --app=http://localhost:3000/caixa
O comprovante sai direto na impressora padrão do Windows (defina a térmica como padrão). Feche todas as janelas do Edge antes de usar o atalho pela primeira vez.

Gaveta de dinheiro na USB: a gaveta ligada à impressora é aberta pelo driver — procure a opção "abrir gaveta" / "cash drawer" nas preferências da impressora no Windows.

9.2 Impressora térmica de rede (ESC/POS)

  1. Ligue a impressora no cabo de rede e descubra o IP dela (normalmente imprimindo a folha de autoteste — segure o botão de avanço ao ligar).
  2. No sistema, escolha Conexão: Térmica de rede direta (ESC/POS), informe o IP e a porta (normalmente 9100).
  3. Salve e clique em Imprimir página de teste. Confira se os acentos (ã, ç, é) saíram corretos.
  4. Opcional: ligue Abrir a gaveta nas vendas em dinheiro.

Nesse modo a impressão é imediata, sem janela. Se a impressora não responder, o sistema avisa e imprime pelo navegador.

9.3 Impressora comum (A4) e PDF

Escolha Papel: Folha A4 para comprovantes detalhados em impressora jato de tinta/laser. O orçamento sai sempre em A4. Em qualquer tela de comprovante, o botão PDF gera o arquivo (funciona até sem internet).

10. Perguntas frequentes e solução de problemas

SituaçãoO que fazer
O leitor de código de barras não lança o produtoClique no campo de busca do caixa (ou tecle F1) e bipe de novo. Teste o leitor no Bloco de Notas: ele deve "digitar" o código e pular a linha.
"Nenhum produto com o código..."O código não está cadastrado. Cadastre o produto (ou acrescente o código de barras ao cadastro existente).
"O preço de X mudou para R$ Y"O preço foi alterado depois que o item entrou no cupom. Remova o item (Del) e bipe de novo.
Desconto pede autorizaçãoO desconto passou do limite do operador. Um gerente digita usuário e PIN na janela que abriu.
"Este caixa já foi fechado"O caixa foi fechado em outro lugar. Abra um novo caixa.
Não consigo fechar o caixaHá vendas offline pendentes. Verifique a conexão e clique em "aguardando envio" no rodapé.
Uma venda offline ficou com erroAvise o administrador: a mensagem aparece junto da venda pendente. Normalmente é um produto excluído ou um caixa fechado antes do envio.
Diferença no fechamento do caixaConfira as sangrias e suprimentos do turno (F7 / relatório do caixa), os trocos e se alguma venda foi lançada na forma de pagamento errada. A diferença fica registrada no histórico de Caixas.
O comprovante sai cortado ou com margemNa janela de impressão do navegador, escolha Margens: nenhuma e o papel da bobina. Confira o tamanho do papel no driver da impressora.
Acentos estranhos na impressora de redeA impressora deve estar no modo ESC/POS com a página de código PC860 (Português). Consulte o manual da impressora.
A tela não mudou depois de uma atualizaçãoFora do caixa, tecle Ctrl+F5 para o navegador buscar a versão nova.
Esqueci minha senhaPeça ao administrador para redefinir a senha em Usuários. Você cria uma nova no próximo acesso.
Esqueci meu PINPeça ao administrador para redefinir o PIN, ou crie outro em Meu perfil (pede a sua senha).
Celular não abre o sistemaO celular precisa estar no Wi-Fi da loja e usar o IP do computador principal (http://IP:3000). Verifique o firewall (item 2.4).
