1. Instalar, abrir e atualizar o sistema

O sistema roda num computador da loja (o “computador principal”) e já traz tudo embutido: o banco de dados, o servidor e as telas. Os caixas, o escritório, tablets e celulares da mesma rede usam o sistema pelo navegador. Há duas formas de instalar.

1.1 O que é necessário

ItemMínimo
SistemaWindows 10 ou 11, 64 bits
Memória (RAM)4 GB (recomendado 8 GB)
Espaço em discocerca de 1 GB para o programa, mais o espaço dos dados (poucos GB em anos de uso)
Leitor de código de barrasQualquer leitor USB que funcione como teclado (o comum nas lojas)
Impressora (opcional)Térmica de 80 ou 58 mm (USB, serial ou rede) ou impressora comum A4 (capítulo 14)
InternetNão é necessária para vender. É usada pelo backup no Google Drive e pelo envio do código de recuperação de senha

Versão do instaladorO instalador publicado no GitHub (1.3.1) é a versão só de estoque. Para o aplicativo com a frente de caixa, gere um instalador novo com npm run dist na pasta do projeto, ou use a forma B.

1.3 Forma A: instalar o aplicativo

  1. Copie o instalador (…-Setup-versão.exe) para o computador e dê dois cliques nele.
  2. Se aparecer a tela azul “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o instalador ainda não tem assinatura digital paga; ele não indica vírus.
  3. Mantenha a pasta sugerida e clique em Instalar. Leva menos de um minuto e não pede senha de administrador do Windows.
  4. Ao terminar, deixe marcada a opção de executar e clique em Concluir. O atalho aparece na Área de Trabalho e no Menu Iniciar.

Ao abrir, a tela de carregamento mostra cada etapa: Iniciando o banco de dados, Atualizando o banco de dados (depois de uma atualização, sem perder dados) e Iniciando o sistema. Leva de 10 a 30 segundos. Na primeira abertura, o aplicativo já entra sozinho como administrador para você criar a sua senha (capítulo 2). Clicar no atalho com o sistema aberto só traz a janela para a frente.

Fechar: clique no X da janela. O sistema salva um último backup e desliga o banco de dados com segurança. Evite encerrar pelo Gerenciador de Tarefas.

1.4 Forma B: pelo código-fonte

  1. Instale o Node.js (nodejs.org, versão LTS) clicando em “Avançar” até o fim. Para conferir, abra o Prompt de Comando (tecla Windows, digite cmd, Enter) e rode node -v.
  2. No Prompt de Comando, entre na pasta do projeto e rode a instalação (alguns minutos na primeira vez): 
    cd "C:\caminho\para\o\projeto"
npm.cmd run setup
    No final aparece a senha provisória do usuário admin. Anote: ela também fica no arquivo apps\api\.env, na linha ADMIN_INITIAL_PASSWORD.
  3. (Opcional) Carregue produtos de exemplo para treinar: npm.cmd run db:demo -w @vl/api
  4. Gere a versão de uso: npm.cmd run build
  5. Ligue o sistema com dois cliques em iniciar-sistema.bat. Abre a janela preta do sistema e, em seguida, o navegador em http://localhost:3000. Entre com admin e a senha provisória (capítulo 2).
Por que “npm.cmd”?No PowerShell, o comando npm pode dar o erro “a execução de scripts foi desabilitada neste sistema”. Escrever npm.cmd evita o problema. Para liberar o npm de vez, rode uma vez no PowerShell Set-ExecutionPolicy -Scope CurrentUser RemoteSigned e responda S.
Não feche a janela preta durante o expedienteEla é o “motor” do sistema. Para desligar, feche essa janela: o banco de dados é desligado com segurança. Para ligar junto com o Windows, aperte Windows+R, digite shell:startup e coloque nessa pasta um atalho para o iniciar-sistema.bat.

1.5 Atualizar para uma nova versão

  1. Feche o sistema.
  2. Aplicativo: execute o instalador da nova versão por cima da atual, sem desinstalar. Código-fonte: atualize os arquivos e rode npm.cmd install, npm.cmd run db:deploy -w @vl/api e npm.cmd run build.
  3. Abra o sistema. O banco de dados é ajustado para a nova versão automaticamente; os dados são mantidos.
  4. Se a nova versão trouxer um Termo de Uso atualizado, cada usuário lê e aceita de novo no próximo acesso.

1.7 Se o sistema não abrir

O que apareceO que fazer

“A execução de scripts foi desabilitada”Use npm.cmd em vez de npm (item 1.4).
“Authentication failed” (senha do banco)O .env tem uma senha diferente da do banco que já existe no computador. Use o .env antigo ou aponte DB_DATA_DIR para uma pasta nova (banco novo).

2. Primeiro acesso

No aplicativo, a primeira abertura entra sozinha como administrador (admin). Pelo código-fonte, entre com admin e a senha provisória da instalação. Em seguida aparece a tela Bem-vindo:

  1. Em Nova senha, crie a sua senha pessoal: mínimo de 8 caracteres, com letras e números. Repita em Confirme a nova senha.
  2. Crie também o seu PIN: 4 a 6 números. Ele confirma operações sensíveis, permite trocar de operador no caixa e, para gerentes, autorizar descontos e cancelamentos.
  3. Informe o seu e-mail. É obrigatório para administradores e serve somente para receber um código se você esquecer a senha (capítulo 3).
  4. Leia o Termo de Uso e Política de Privacidade (clique no link) e marque “Li e concordo”.
  5. Clique em Salvar e continuar.

Os funcionários que você cadastrar passam pelo mesmo processo no primeiro login com a senha provisória que você definir. O operador de caixa, depois disso, cai direto na frente de caixa.

Depois do primeiro acessoSiga para o capítulo 4 e configure a loja: nome e logotipo, formas de pagamento, impressora e a conta de e-mail da recuperação de senha. Depois cadastre os funcionários (capítulo 5) e os produtos (capítulo 6).

3. Entrando no sistema

  1. Abra o sistema (atalho do aplicativo ou http://localhost:3000 no navegador).
  2. Digite o seu usuário e a sua senha e clique em Entrar.

PIN rápido: a aba PIN rápido permite entrar só com o usuário e o PIN, útil na troca de turno do caixa.

SegurançaDepois de 5 senhas ou PINs errados, o usuário fica bloqueado por 15 minutos. Para sair, use Sair no fim do menu lateral, principalmente em computadores compartilhados.

Esqueci minha senha

  1. Na tela de login, clique em Esqueci minha senha.
  2. Digite o seu usuário ou e-mail e clique em Enviar código.
  3. Abra o seu e-mail: chega uma mensagem com o nome da loja e um código de 6 números (veja também a caixa de spam).
  4. Digite o código, crie a nova senha e clique em Salvar nova senha.
Bom saberO código vale por 15 minutos e só pode ser usado uma vez. Depois de 5 códigos errados é preciso pedir outro; são no máximo 3 pedidos por hora. Ao redefinir, as sessões abertas em outros aparelhos são encerradas. Quem não tem e-mail cadastrado, ou se a recuperação ainda não foi configurada (capítulo 4), pede a um administrador para usar Redefinir senha.

4.2 Formas de pagamento

Já vêm prontas: Dinheiro, PIX, Cartão de crédito, Cartão de débito, Vale-alimentação e Vale-refeição (ativas), além de Cheque e Outros (desativadas). Em Nova forma você cria outras. Para cada forma:

OpçãoO que faz
Ordem (setas ↑ ↓)Ordem no caixa. As oito primeiras ativas ganham os atalhos F1–F4 e F6–F9 na tela de pagamento (F5 confirma).
AtivaDesativada, não aparece no caixa; o histórico continua. Formas já usadas não podem ser excluídas, só desativadas.
Dá trocoAceita valor maior que o devido (normalmente só o dinheiro). O troco sai sempre da gaveta.
Exige clienteSó aceita a forma com o cliente da venda identificado (ex.: crediário).
Taxa e prazoTaxa da operadora e dias para receber (ex.: crédito D+30), guardados para o controle financeiro.

A forma Dinheiro é a única que entra na gaveta e não pode ser desativada.

4.4 Recuperação de senha por e-mail (Gmail)

  1. Na Conta Google da loja, ative a Verificação em duas etapas (myaccount.google.com › Segurança).
  2. Abra myaccount.google.com/apppasswords, crie uma senha de app com o nome do sistema (ex.: “Caixa da loja”) e copie os 16 caracteres.
  3. Em Configurações › Recuperação de senha por e-mail, escolha Gmail, informe o e-mail da conta e cole a senha de app. O nome do remetente pode ficar em branco: usa o nome da loja. Clique em Salvar.
  4. Clique em Enviar e-mail de teste. Se chegar ao seu e-mail (cadastrado em Meu perfil), o selo muda para Ativa.
SegurançaUse sempre a senha de app, nunca a senha normal do Gmail. Ela fica guardada criptografada no sistema, não aparece em nenhuma tela e pode ser revogada a qualquer momento na Conta Google. Outros provedores funcionam pela opção SMTP.

4.5 Empresa e privacidade (LGPD)

Razão social, CNPJ, endereço e o encarregado de dados (nome e e-mail). Aparecem no Termo de Uso. Se a razão social ficar em branco, o termo usa o nome da loja.

5. Usuários e permissões

Somente o administrador. Cada funcionário deve ter o próprio usuário: o sistema registra quem fez cada operação.

  1. No menu, clique em Usuários e em Novo usuário.
  2. Preencha o Nome completo, o E-mail (obrigatório para administradores), o perfil, o Login (ex.: maria.silva), uma Senha provisória e, se quiser, o PIN.
  3. Passe o login e a senha provisória ao funcionário. No primeiro acesso, ele cria a própria senha e o PIN e lê o termo.
Todo operador e gerente deve ter PINO PIN serve para trocar de operador no caixa e, no caso dos gerentes, para autorizar descontos, cancelamentos e sangrias.
SituaçãoO que fazer
Esqueceu a senhaCom e-mail cadastrado: o próprio funcionário usa Esqueci minha senha. Sem e-mail: Redefinir senha (nova senha provisória).
Esqueceu o PINRedefinir PIN.
Saiu da lojaDesativar: o acesso é bloqueado na hora e o histórico é mantido. Dá para Reativar depois.
Ex-funcionário pediu a exclusão dos dadosCom o usuário desativado, Anonimizar dados (LGPD) (capítulo 16).

Em Auditoria, o administrador vê o registro de tudo o que foi feito: logins, vendas, descontos (e quem autorizou), itens removidos do cupom, cancelamentos, sangrias, cadastros, exclusões e alterações. Cada pessoa troca a própria senha, PIN e e-mail em Meu perfil, clicando no próprio nome no fim do menu.

Cadastrar um produto

  1. Menu Produtos › Novo produto.
  2. Preencha os campos. Para o código de barras, clique no campo e bipe o produto.
  3. Clique em Cadastrar produto e confirme com o PIN.
CampoO que colocar
NomeMarca, tipo e tamanho. Ex.: Arroz Tio João Tipo 1 5kg.
SKUCódigo interno, sem espaços (ex.: ARROZ-TJ-5KG). Também serve para vender no caixa.
Código de barras (EAN)Bipe a embalagem. Pão e frios podem ficar sem: vendem pelo SKU ou pelo nome.
Categoria e unidadeA unidade define como é vendido: UN, KG (por peso), L, CX, PCT…

Preço de custoUsado na margem do relatório de vendas.

Controlar consumo e reposição (opcional)

Ligado (padrão): informe o consumo médio por dia, o consumo máximo por dia e o prazo de entrega. O sistema calcula:

IndicadorFórmulaPara que serve
Estoque mínimo (EM)consumo médio × prazoO que se consome enquanto a entrega não chega.
Estoque de segurança (ES)(máximo − médio) × prazoProteção contra dias de pico.
Ponto de pedido (PP)EM + ESAo chegar nele, o sistema gera a solicitação de pedido.

Desligado: para itens que não se repõem por previsão (sacolas, itens sazonais). Continuam com estoque e preço, só não geram pedido automático.

ExemploPão de forma: média 10 por dia, máximo 16, entrega em 3 dias. EM = 10 × 3 = 30; ES = (16 − 10) × 3 = 18; PP = 48. Com 48 ou menos, o sistema pede reposição.

Encontrar e editar: em Produtos, busque por nome, SKU ou código. As abas filtram por situação. Clique no produto para ver os detalhes, o histórico e o botão Editar.

7. Clientes

O cadastro de clientes é opcional. Ele permite identificar o cliente na venda, imprimir o CPF/CNPJ no comprovante e ver o histórico de compras. Menu Clientes, ou direto no caixa pela tecla Ins (capítulo 8).

Cadastrar

  1. Novo cliente. Informe o nome e, se o cliente quiser, CPF ou CNPJ (validado pelos dígitos), telefone, e-mail, nascimento e endereço.
  2. Privacidade (LGPD): para guardar qualquer dado além do nome, ligue O cliente autorizou o cadastro dos dados pessoais e escolha como ele autorizou (balcão, telefone…). Sem isso o sistema não salva.
  3. “Aceita receber ofertas” é um consentimento separado, só para comunicação de marketing.

Consultar e atender pedidos do cliente

Clique no cliente para ver o resumo (número de compras, total e ticket médio), os dados e as compras. Gerente e administrador também têm:

BotãoQuando usar
InativarCliente que não compra mais: some das buscas do caixa, o histórico continua.
Exportar dadosO cliente pediu uma cópia dos dados: baixa um arquivo com o cadastro e as compras para entregar a ele.
Apagar dados (LGPD)O cliente pediu a exclusão: nome, CPF, telefone, e-mail, endereço e observações são apagados definitivamente. As compras continuam registradas, sem identificar a pessoa. Se ele pediu também a cópia, exporte antes.

8. Frente de caixa

A frente de caixa ocupa a tela inteira e funciona toda pelo teclado; as teclas também aparecem como botões para telas touch. O operador de caixa entra direto nela; os demais perfis usam o menu Frente de caixa.

8.1 Abrir o caixa

  1. Confira o nome do terminal (ex.: Caixa 01). Cada computador de caixa tem um nome diferente, que fica salvo nele.
  2. Conte o dinheiro de troco colocado na gaveta e digite em Troco inicial.
  3. Clique em Abrir caixa. A abertura precisa de conexão com o computador principal.

8.2 Registrar uma venda

  1. Bipe o produto. Ele entra no cupom com um bipe curto; bipar de novo soma a quantidade.
  2. Sem código: digite parte do nome ou o SKU, escolha com ↑ ↓ e tecle Enter.
  3. Várias unidades: quantidade, asterisco e código: 3*7891234567890.
  4. Quantidade e peso: F2 (aceita 0,455 kg) ou + / −.
  5. Remover item: Del. Cancelar o cupom inteiro: Esc. Os dois ficam na auditoria.
  6. Ao terminar, tecle F5 (Finalizar venda).

8.3 Cliente e CPF na nota (Ins)

  1. Tecle Ins e busque o cliente por nome, CPF ou telefone. Enter escolhe.
  2. Só o CPF/CNPJ na nota, sem cadastro: digite o documento e tecle Enter (ou Usar só o documento).
  3. Cadastrar cliente faz um cadastro rápido, com a autorização do cliente (LGPD).

O cliente e o documento saem no comprovante. Sem internet, a busca usa os clientes salvos no computador do caixa; o cadastro de cliente novo precisa de conexão.

8.4 Descontos e autorização do gerente

F3: desconto no item selecionado. F4: no total. Escolha % ou R$. Acima do limite do operador, abre a Autorização do supervisor: o gerente digita o próprio usuário e PIN ali mesmo.

8.5 Pagamento e troco

  1. Escolha a forma de pagamento pelas teclas mostradas em cada botão (F1 a F4, F6 a F9, conforme a ordem em Configurações).
  2. Digite o valor e tecle Enter. O sistema sugere o valor que falta.
  3. Para misturar formas (ex.: R$ 20 no PIX + o resto em dinheiro), lance uma, depois a outra.
  4. No dinheiro, o troco aparece em verde enquanto você digita. Use os botões de notas.
  5. Quando fechar, tecle F5 para confirmar.
RegrasTroco só sai de forma que “dá troco” (o dinheiro). Formas marcadas como “exige cliente” só ficam disponíveis com o cliente identificado (Ins).

8.6 Comprovante, PDF e orçamento

Ao confirmar, aparece Venda concluída com o número e o troco. Escolha Imprimir ou PDF; Esc começa a próxima venda.

Orçamento (F8): com itens no cupom, gera um orçamento em A4 ou PDF. Não é venda e não baixa estoque.

8.7 Sangria e suprimento (F6)

Sangria é retirar dinheiro da gaveta; suprimento, colocar. A justificativa é obrigatória, o operador precisa da autorização de um gerente e sai um comprovante para assinatura. A sangria não pode passar do dinheiro esperado na gaveta.

8.8 Reimprimir e cancelar vendas (F7)

F7 lista as vendas do caixa aberto. Clique numa venda para Reimprimir (2ª via), gerar PDF ou Cancelar venda com motivo: os produtos voltam ao estoque. O operador precisa da autorização do gerente; só dá para cancelar vendas do caixa ainda aberto.

8.9 Trocar de operador (F9)

Com o cupom vazio, o próximo operador digita o usuário e o PIN. O caixa continua aberto e as vendas seguintes ficam no nome dele.

8.10 Fechar o caixa (F10)

  1. Com o cupom vazio, tecle F10. Aparece o resumo: vendas, totais por forma de pagamento, troco inicial, sangrias, suprimentos e o dinheiro esperado na gaveta.
  2. Conte o dinheiro e digite em Dinheiro contado. O sistema mostra se confere, tem falta ou sobra.
  3. Clique em Fechar caixa e imprimir. O relatório sai para assinatura.

9. Entradas e saídas de estoque

As vendas do caixa já baixam o estoque sozinhas. Estas telas são para o que não passa pelo caixa.

Registrar entrada

  1. Menu Registrar entrada. Escolha Pedido recebido ou Retorno ao estoque.

13. Excluir e recuperar produtos

  1. Abra o produto e clique em Excluir › Mover para a lixeira (o PIN é pedido).
  2. O produto some das listas, mas pode voltar com Restaurar durante o prazo (padrão: 15 dias), em Lixeira.
  3. Passado o prazo, ele é apagado definitivamente, com o histórico. Produtos que já foram vendidos no caixa nunca são apagados de vez: o histórico de vendas é preservado.
AtençãoA exclusão definitiva não pode ser desfeita.

14. Impressoras

O sistema imprime comprovante de venda, orçamento, sangria/suprimento e fechamento de caixa. Todo comprovante traz “Documento Não Fiscal — Sem Valor Fiscal”.

Térmica USB ou serial (mais comum)

  1. Instale o driver do fabricante (Epson, Elgin, Bematech, Daruma, Tanca…) e imprima uma página de teste pelo Windows.
  2. Em Configurações, escolha Bobina 80 mm (ou 58 mm) e Impressora do Windows.
  3. Na primeira impressão, escolha a térmica, Margens: nenhuma e desmarque Cabeçalhos e rodapés. O navegador lembra a escolha.
Imprimir sem a janela de confirmaçãoCrie um atalho com o destino:
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk-printing --app=http://localhost:3000/caixa
e defina a térmica como impressora padrão do Windows. A gaveta de dinheiro ligada à impressora USB abre pelo driver (opção “abrir gaveta”).

Térmica de rede (ESC/POS)

  1. Ligue a impressora na rede e descubra o IP dela (folha de autoteste).
  2. Em Configurações, escolha Térmica de rede direta, informe o IP e a porta (normalmente 9100) e salve.
  3. Imprimir página de teste e confira os acentos. Se quiser, ligue Abrir a gaveta nas vendas em dinheiro.

Nesse modo a impressão é imediata, sem janela. Se a impressora não responder, o sistema avisa e imprime pelo navegador.

A4 e PDF

Escolha Folha A4 para impressoras comuns. O orçamento sai sempre em A4. Em qualquer comprovante, o botão PDF gera o arquivo, mesmo sem internet.

15. Backup

Aplicativo: automático no Google Drive

  1. Instale o Google Drive para computador e entre com a conta Google da loja.
  2. Feche e abra o sistema. Ele encontra a pasta Meu Drive e avisa: “Backup automático no Google Drive ativado”.

Uma cópia é salva ao abrir, a cada 4 horas e ao fechar, na pasta Meu Drive › VL Estoque - Backups. Ficam os últimos 30 dias. Sem o Drive, os backups ficam em %LOCALAPPDATA%\VLEstoque\backups.

Computador novo ou com defeito: instale o Google Drive (mesma conta) e o aplicativo. Na primeira abertura, o sistema encontra o backup e pergunta se deseja restaurar: clique em Restaurar dados.

Código-fonte: cópia manual

  1. Desligue o sistema (feche a janela preta).
  2. Copie a pasta do banco (DB_DATA_DIR) e o arquivo apps\api\.env para um pen drive ou HD externo. Sem o .env, o banco copiado não abre.
  3. Faça pelo menos uma vez por semana e guarde fora da loja.
Nunca coloque a pasta viva do banco no OneDrive ou no Google DriveA sincronização pode corromper o banco enquanto o sistema está ligado. Só os arquivos de backup podem ir para a nuvem.

16. Privacidade e LGPD

O sistema trata dados pessoais de quem o usa (nome, login, e-mail e registro das ações) e, na frente de caixa, dos clientes cadastrados. Ele ajuda a empresa a cumprir a LGPD (Lei nº 13.709/2018).

Termo de Uso e Política de Privacidade

Explica quais dados são tratados, para quê, por quanto tempo e os direitos de cada pessoa, inclusive dos clientes. Todo usuário dá ciência no primeiro acesso; o termo fica sempre em Termos e privacidade, no menu, e no link da tela de login. Se o termo mudar, o sistema pede nova leitura (e, enquanto isso, guarda as vendas offline do usuário sem perdê-las).

Para o administradorPreencha os dados da empresa e do encarregado de dados em Configurações › Empresa e privacidade. O texto do termo é um modelo: revise com um profissional jurídico.

Direitos dos usuários (funcionários)

DireitoComo exercer
Ver os próprios dadosMeu perfil › Baixar meus dados: cadastro, auditoria, operações de estoque, vendas feitas e caixas abertos.
Corrigir o e-mailMeu perfil, confirmando com a senha atual.
Corrigir o nomePedir a um administrador.
Eliminação ou anonimizaçãoO administrador desativa o usuário e usa Anonimizar dados (LGPD). As operações continuam no histórico sem identificar a pessoa.

Direitos dos clientes

O cliente pede a um gerente ou administrador, que no cadastro dele usa Exportar dados ou Apagar dados (LGPD) (capítulo 7). Dados pessoais de clientes só são guardados com a autorização registrada, e ofertas exigem consentimento separado.

O prazo legal para responder aos pedidos é de 15 dias.

O que o sistema faz sozinho

  • Guarda senhas e PINs de forma irreversível.
  • Guarda a senha da conta de e-mail de envio criptografada.
  • Apaga o endereço IP da auditoria depois de 12 meses e os códigos de recuperação em até 1 dia.
  • Apaga do computador do caixa a cópia dos clientes ao sair do sistema.
  • Registra na auditoria aceites do termo, exportações e anonimizações.

17. Celular e uso sem internet

Outros computadores, tablets e celulares

  1. No computador principal, descubra o IP (no cmd, rode ipconfig; ex.: 192.168.0.10).
  2. No outro aparelho, no mesmo Wi-Fi, abra http://IP:3000 (código-fonte) ou http://IP:3030 (aplicativo).
  3. No menu do navegador, toque em Instalar app (ou Adicionar à tela inicial).

Sem internet

No computador principal, o sistema funciona sem internet. Nos outros aparelhos, se a rede cair:

  • O caixa continua vendendo: o rodapé mostra “Offline — vendendo neste computador”, cada venda fica guardada no aparelho e o comprovante sai normalmente (o número aparece depois).
  • Entradas e saídas de estoque também ficam guardadas.
  • Quando a conexão volta, tudo é enviado sozinho, sem duplicar.
Precisa de conexãoAbrir e fechar o caixa, sangria e suprimento, cancelar vendas, autorização do gerente para descontos acima do limite e cadastro de cliente novo. O fechamento fica bloqueado enquanto houver vendas offline não enviadas.
