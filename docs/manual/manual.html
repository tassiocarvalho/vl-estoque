1. Instalar, abrir e atualizar o sistema

O sistema roda num computador da loja (o “computador principal”) e já traz tudo embutido: o banco de dados, o servidor e as telas. Os caixas, o escritório, tablets e celulares da mesma rede usam o sistema pelo navegador. Há duas formas de instalar.

1.1 O que é necessário

ItemMínimo
SistemaWindows 10 ou 11, 64 bits
Memória (RAM)4 GB (recomendado 8 GB)
Espaço em discocerca de 1 GB para o programa, mais o espaço dos dados (poucos GB em anos de uso)
Leitor de código de barrasQualquer leitor USB que funcione como teclado (o comum nas lojas)

InternetNão é necessária para vender. É usada pelo backup no Google Drive e pelo envio do código de recuperação de senha

Versão do instaladorO instalador publicado no GitHub (1.3.1) é a versão só de estoque. Para o aplicativo com a frente de caixa, as compras e o financeiro, gere um instalador novo com npm run dist na pasta do projeto (ele também gera este manual em PDF), ou use a forma B.

1.3 Forma A: instalar o aplicativo

  1. Copie o instalador (…-Setup-versão.exe) para o computador e dê dois cliques nele.
  2. Se aparecer a tela azul “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o instalador ainda não tem assinatura digital paga; ele não indica vírus.
  3. Mantenha a pasta sugerida e clique em Instalar. Leva menos de um minuto e não pede senha de administrador do Windows.
  4. Ao terminar, deixe marcada a opção de executar e clique em Concluir. O atalho aparece na Área de Trabalho e no Menu Iniciar.

Ao abrir, a tela de carregamento mostra cada etapa: Iniciando o banco de dados, Atualizando o banco de dados (depois de uma atualização, sem perder dados) e Iniciando o sistema. Leva de 10 a 30 segundos. Na primeira abertura, o aplicativo já entra sozinho como administrador para você criar a sua senha (capítulo 2). Clicar no atalho com o sistema aberto só traz a janela para a frente.

Fechar: clique no X da janela. O sistema salva um último backup e desliga o banco de dados com segurança. Evite encerrar pelo Gerenciador de Tarefas.

1.4 Forma B: pelo código-fonte

  1. Instale o Node.js (nodejs.org, versão LTS) clicando em “Avançar” até o fim. Para conferir, abra o Prompt de Comando (tecla Windows, digite cmd, Enter) e rode node -v.
  2. No Prompt de Comando, entre na pasta do projeto e rode a instalação (alguns minutos na primeira vez): 
    cd "C:\caminho\para\o\projeto"
npm.cmd run setup
    No final aparece a senha provisória do usuário admin. Anote: ela também fica no arquivo apps\api\.env, na linha ADMIN_INITIAL_PASSWORD.
  3. (Opcional) Carregue produtos de exemplo para treinar: npm.cmd run db:demo -w @vl/api
  4. Gere a versão de uso: npm.cmd run build
  5. Ligue o sistema com dois cliques em iniciar-sistema.bat. Abre a janela preta do sistema e, em seguida, o navegador em http://localhost:3000. Entre com admin e a senha provisória (capítulo 2).
Por que “npm.cmd”?No PowerShell, o comando npm pode dar o erro “a execução de scripts foi desabilitada neste sistema”. Escrever npm.cmd evita o problema. Para liberar o npm de vez, rode uma vez no PowerShell Set-ExecutionPolicy -Scope CurrentUser RemoteSigned e responda S.
Não feche a janela preta durante o expedienteEla é o “motor” do sistema. Para desligar, feche essa janela: o banco de dados é desligado com segurança. Para ligar junto com o Windows, aperte Windows+R, digite shell:startup e coloque nessa pasta um atalho para o iniciar-sistema.bat.

1.5 Atualizar para uma nova versão

  1. Feche o sistema.
  2. Aplicativo: execute o instalador da nova versão por cima da atual, sem desinstalar. Código-fonte: atualize os arquivos (git pull) e rode npm.cmd install e npm.cmd run build. O iniciar-sistema.bat aplica sozinho as atualizações do banco de dados toda vez que liga o sistema.
  3. Abra o sistema. O banco de dados é ajustado para a nova versão automaticamente; os dados são mantidos. Por precaução, faça um backup antes (capítulo 18).
  4. Se a nova versão trouxer um Termo de Uso atualizado, cada usuário lê e aceita de novo no próximo acesso.

2. Primeiro acesso

No aplicativo, a primeira abertura entra sozinha como administrador (admin). Pelo código-fonte, entre com admin e a senha provisória da instalação. Em seguida aparece a tela Bem-vindo:

  1. Em Nova senha, crie a sua senha pessoal: mínimo de 8 caracteres, com letras e números. Repita em Confirme a nova senha.
  2. Crie também o seu PIN: 4 a 6 números. Ele confirma operações sensíveis, permite trocar de operador no caixa e, para gerentes, autorizar descontos e cancelamentos.
  3. Informe o seu e-mail. É obrigatório para administradores e serve somente para receber um código se você esquecer a senha (capítulo 3).
  4. Leia o Termo de Uso e Política de Privacidade (clique no link) e marque “Li e concordo”.
  5. Clique em Salvar e continuar.

Os funcionários que você cadastrar passam pelo mesmo processo no primeiro login com a senha provisória que você definir. O operador de caixa, depois disso, cai direto na frente de caixa.

Depois do primeiro acessoSiga para o capítulo 5 e configure a loja: nome e logotipo, formas de pagamento, impressora, regras de troca e fiado e a conta de e-mail da recuperação de senha. Depois cadastre os funcionários (capítulo 6), os fornecedores (capítulo 11) e os produtos (capítulo 7; uma planilha do Excel agiliza).

3. Entrando no sistema

  1. Abra o sistema (atalho do aplicativo ou http://localhost:3000 no navegador).
  2. Digite o seu usuário e a sua senha e clique em Entrar.

PIN rápido: a aba PIN rápido permite entrar só com o usuário e o PIN, útil na troca de turno do caixa.

SegurançaDepois de 5 senhas ou PINs errados, o usuário fica bloqueado por 15 minutos. Para sair, use Sair no fim do menu lateral, principalmente em computadores compartilhados.

Esqueci minha senha

  1. Na tela de login, clique em Esqueci minha senha.
  2. Digite o seu usuário ou e-mail e clique em Enviar código.
  3. Abra o seu e-mail: chega uma mensagem com o nome da loja e um código de 6 números (veja também a caixa de spam).
  4. Digite o código, crie a nova senha e clique em Salvar nova senha.
Bom saberO código vale por 15 minutos e só pode ser usado uma vez. Depois de 5 códigos errados é preciso pedir outro; são no máximo 3 pedidos por hora. Ao redefinir, as sessões abertas em outros aparelhos são encerradas. Quem não tem e-mail cadastrado, ou se a recuperação ainda não foi configurada (capítulo 5), pede a um administrador para usar Redefinir senha.

4. Menu e busca rápida

O menu lateral reúne as telas em grupos: Operação (painel, frente de caixa, entradas e saídas), Vendas (vendas, caixas e clientes), Estoque (produtos, categorias, movimentações, pedidos, notas de entrada, fornecedores e relatórios), Financeiro (fluxo de caixa e resultado, fiado e contas a pagar) e Administração. Cada pessoa só vê as telas que o seu perfil permite.

4.1 Recolher o menu

Clique em Recolher menu, no fim do menu, para deixar só os ícones e ganhar espaço na tela (passe o mouse sobre um ícone para ver o nome). Clique de novo para abrir. Cada computador lembra a sua escolha.

4.2 Busca rápida (Ctrl+K)

Em qualquer tela, tecle Ctrl+K (ou clique em Buscar…, no topo do menu) e digite o que procura: o nome de uma tela (“fiado”, “nota”, “aluguel”…), um produto (nome, SKU ou código de barras) ou um cliente. Use ↑ ↓ e Enter para abrir; Esc fecha.

5.2 Formas de pagamento

Já vêm prontas: Dinheiro, PIX, Cartão de crédito, Cartão de débito, Vale-alimentação, Vale-refeição, Vale-troca / crédito e Fiado / crediário (ativas), além de Cheque e Outros (desativadas). Em Nova forma você cria outras. Para cada forma:

OpçãoO que faz
Ordem (setas ↑ ↓)Ordem no caixa. As oito primeiras ativas ganham os atalhos F1–F4 e F6–F9 na tela de pagamento (F5 confirma).
AtivaDesativada, não aparece no caixa; o histórico continua. Formas já usadas não podem ser excluídas, só desativadas.
Dá trocoAceita valor maior que o devido (normalmente só o dinheiro). O troco sai sempre da gaveta.
Exige clienteSó aceita a forma com o cliente da venda identificado (ex.: crediário).
Taxa e prazoTaxa da operadora (%) e dias para o dinheiro cair (ex.: crédito 3,49% em D+30, débito 1,39% em D+1). O fluxo de caixa coloca cada venda no cartão no dia em que o dinheiro cai, já sem a taxa, e o resultado do mês desconta as taxas (capítulo 15).

A forma Dinheiro é a única que entra na gaveta e não pode ser desativada. Vale-troca e Fiado são formas especiais: não dão troco, o tipo não pode ser mudado e o fiado sempre exige o cliente. Se a loja não trabalha com fiado, basta desativar a forma.

5.4 Balança (etiqueta com peso ou preço)

Para a balança que imprime etiqueta com código de barras (frios, carnes, hortifrúti a granel). A etiqueta segue o formato mais comum no Brasil: 2 CCCC 0PPPPP D, em que 2 é o primeiro dígito, CCCC é o código do produto na balança (PLU), PPPPP é o preço total (em centavos) ou o peso (em gramas) e D é o dígito verificador.

  1. Ligue Ler etiquetas da balança no caixa.
  2. Em A etiqueta traz, escolha o que a balança imprime: o preço total (mais comum) ou o peso em gramas.
  3. Informe quantos dígitos tem o código do produto (4, 5 ou 6, igual ao programado na balança) e o primeiro dígito da etiqueta (quase sempre 2). Salve.
  4. Em cada produto pesado, preencha o Código na balança (PLU) com o mesmo número cadastrado na balança (capítulo 7).
Como o caixa calculaNa etiqueta de preço, o caixa calcula o peso a partir do preço do cadastro e cobra exatamente o valor impresso (nunca mais). Na etiqueta de peso, cobra o peso × o preço do cadastro. O estoque baixa pelo peso.

5.6 Recuperação de senha por e-mail (Gmail)

  1. Na Conta Google da loja, ative a Verificação em duas etapas (myaccount.google.com › Segurança).
  2. Abra myaccount.google.com/apppasswords, crie uma senha de app com o nome do sistema (ex.: “Caixa da loja”) e copie os 16 caracteres.
  3. Em Configurações › Recuperação de senha por e-mail, escolha Gmail, informe o e-mail da conta e cole a senha de app. O nome do remetente pode ficar em branco: usa o nome da loja. Clique em Salvar.
  4. Clique em Enviar e-mail de teste. Se chegar ao seu e-mail (cadastrado em Meu perfil), o selo muda para Ativa.
SegurançaUse sempre a senha de app, nunca a senha normal do Gmail. Ela fica guardada criptografada no sistema, não aparece em nenhuma tela e pode ser revogada a qualquer momento na Conta Google. Outros provedores funcionam pela opção SMTP.

Controlar consumo e reposição (opcional)

Ligado (padrão): informe o consumo médio por dia, o consumo máximo por dia e o prazo de entrega. O sistema calcula:

IndicadorFórmulaPara que serve
Estoque mínimo (EM)consumo médio × prazoO que se consome enquanto a entrega não chega.
Estoque de segurança (ES)(máximo − médio) × prazoProteção contra dias de pico.
Ponto de pedido (PP)EM + ESAo chegar nele, o sistema gera a solicitação de pedido.

Desligado: para itens que não se repõem por previsão (sacolas, itens sazonais). Continuam com estoque e preço, só não geram pedido automático.

ExemploPão de forma: média 10 por dia, máximo 16, entrega em 3 dias. EM = 10 × 3 = 30; ES = (16 − 10) × 3 = 18; PP = 48. Com 48 ou menos, o sistema pede reposição.

Encontrar e editar: em Produtos, busque por nome, SKU ou código. As abas filtram por situação. Clique no produto para ver os detalhes, o histórico e o botão Editar.

Na tela do produto aparecem também o custo médio, o último custo pago na nota, a margem sobre a venda e os fornecedores que já entregaram o produto, com o código dele no fornecedor e a embalagem (ex.: caixa com 12).

Kits e combos

Um kit é um produto vendido como um item só, mas formado por outros produtos: cesta básica, “café da manhã”, combo de lanche. Ele não tem estoque próprio: a venda do kit baixa o estoque de cada item.

  1. Novo produto, preencha nome, SKU e categoria e ligue Kit / combo.
  2. Em Itens do kit, clique em Adicionar item, escolha cada produto e a quantidade que vai no kit.
  3. Defina o preço de venda do kit. O custo é a soma dos itens e a margem aparece na hora.

Na tela do kit, Kits disponíveis mostra quantos dá para montar com o estoque atual dos itens. Kits não recebem entrada de estoque, não entram em nota de entrada e não geram pedido de reposição (os itens, sim). Cancelar ou devolver um kit devolve os itens ao estoque.

Cadastrar e atualizar por planilha (Excel)

Para cadastrar muitos produtos de uma vez ou atualizar preços em massa.

  1. Em Produtos, clique em Importar planilha e baixe o modelo (ou use Exportar planilha para baixar o catálogo atual já no formato certo).
  2. Preencha no Excel: nome, SKU, código de barras, categoria, subcategoria, unidade, preço de venda, custo, estoque inicial e reposição (sim/não). Salve como CSV (separado por ponto e vírgula).
  3. Escolha o arquivo e o modo: Cadastrar e atualizar (SKU que já existe é atualizado; célula vazia mantém o valor) ou Só cadastrar novos. Se quiser, deixe o sistema criar as categorias que faltam.
  4. Clique em Conferir planilha. O sistema mostra quantos produtos são novos, quantos serão atualizados e os erros linha a linha. Nada é gravado nessa etapa.
  5. Com tudo certo, clique em Importar. Ou é tudo gravado, ou nada.
Acentos e códigos de barrasO sistema entende o CSV salvo pelo Excel em português (acentos preservados). Formate a coluna do código de barras como texto, senão o Excel transforma o número em notação científica. O estoque inicial só vale para produtos novos: para corrigir o saldo de um produto existente, use um ajuste de estoque.

8. Clientes

O cadastro de clientes é opcional. Ele permite identificar o cliente na venda, imprimir o CPF/CNPJ no comprovante e ver o histórico de compras. Menu Clientes, ou direto no caixa pela tecla Ins (capítulo 9).

Cadastrar

  1. Novo cliente. Informe o nome e, se o cliente quiser, CPF ou CNPJ (validado pelos dígitos), telefone, e-mail, nascimento e endereço.
  2. Privacidade (LGPD): para guardar qualquer dado além do nome, ligue O cliente autorizou o cadastro dos dados pessoais e escolha como ele autorizou (balcão, telefone…). Sem isso o sistema não salva.
  3. “Aceita receber ofertas” é um consentimento separado, só para comunicação de marketing.

Limite de fiado

No cadastro, o campo Limite de fiado (R$) define quanto o cliente pode dever ao mesmo tempo. O cliente novo recebe o limite padrão das configurações (capítulo 5.5). Com limite zero, cada venda no fiado precisa da liberação do gerente.

Consultar e atender pedidos do cliente

Clique no cliente para ver o resumo (número de compras, total e ticket médio), os dados e as compras. O quadro de fiado mostra o limite, o valor em aberto, o vencido e o disponível, com as abas Parcelas, Recebimentos e Vales-troca do cliente.

Gerente e administrador também têm:

BotãoQuando usar
InativarCliente que não compra mais: some das buscas do caixa, o histórico continua.
Exportar dadosO cliente pediu uma cópia dos dados: baixa um arquivo com o cadastro e as compras para entregar a ele.
Apagar dados (LGPD)O cliente pediu a exclusão: nome, CPF, telefone, e-mail, endereço e observações são apagados definitivamente. As compras continuam registradas, sem identificar a pessoa. Se ele pediu também a cópia, exporte antes. Cliente com fiado em aberto não pode ser apagado até quitar (ou o gerente cancelar o saldo).

9. Frente de caixa

A frente de caixa ocupa a tela inteira e funciona toda pelo teclado; as teclas também aparecem como botões para telas touch. O operador de caixa entra direto nela; os demais perfis usam o menu Frente de caixa.

9.1 Abrir o caixa

  1. Confira o nome do terminal (ex.: Caixa 01). Cada computador de caixa tem um nome diferente, que fica salvo nele.
  2. Conte o dinheiro de troco colocado na gaveta e digite em Troco inicial.
  3. Clique em Abrir caixa. A abertura precisa de conexão com o computador principal.

9.2 Registrar uma venda

  1. Bipe o produto. Ele entra no cupom com um bipe curto; bipar de novo soma a quantidade.
  2. Sem código: digite parte do nome ou o SKU, escolha com ↑ ↓ e tecle Enter.
  3. Várias unidades: quantidade, asterisco e código: 3*7891234567890.
  4. Quantidade e peso: F2 (aceita 0,455 kg) ou + / −.
  5. Remover item: Del. Cancelar o cupom inteiro: Esc. Os dois ficam na auditoria.
  6. Etiqueta da balança: bipe a etiqueta normalmente. O caixa reconhece o produto pelo código da balança e lança o peso e o valor da etiqueta (com a balança configurada, capítulo 5.4).
  7. Kit / combo: entra como um item só, com o preço do kit; o estoque baixa de cada item do kit.
  8. Ao terminar, tecle F5 (Finalizar venda).

9.3 Cliente e CPF na nota (Ins)

  1. Tecle Ins e busque o cliente por nome, CPF ou telefone. Enter escolhe.
  2. Só o CPF/CNPJ na nota, sem cadastro: digite o documento e tecle Enter (ou Usar só o documento).
  3. Cadastrar cliente faz um cadastro rápido, com a autorização do cliente (LGPD).

O cliente e o documento saem no comprovante. Sem internet, a busca usa os clientes salvos no computador do caixa; o cadastro de cliente novo precisa de conexão.

9.4 Descontos e autorização do gerente

F3: desconto no item selecionado. F4: no total. Escolha % ou R$. Acima do limite do operador, abre a Autorização do supervisor: o gerente digita o próprio usuário e PIN ali mesmo.

9.5 Pagamento e troco

  1. Escolha a forma de pagamento pelas teclas mostradas em cada botão (F1 a F4, F6 a F9, conforme a ordem em Configurações).
  2. Digite o valor e tecle Enter. O sistema sugere o valor que falta.
  3. Para misturar formas (ex.: R$ 20 no PIX + o resto em dinheiro), lance uma, depois a outra.
  4. No dinheiro, o troco aparece em verde enquanto você digita. Use os botões de notas.
  5. Quando fechar, tecle F5 para confirmar.
RegrasTroco só sai de forma que “dá troco” (o dinheiro). Formas marcadas como “exige cliente” só ficam disponíveis com o cliente identificado (Ins).

Pagar com vale-troca

Escolha Vale-troca / crédito, digite o código do vale (ex.: VT-LUT6R27T) e confirme: o sistema mostra o saldo e lança o valor (no máximo o que falta). Se sobrar saldo, o vale continua valendo para outra compra. Na troca feita pelo próprio caixa (item 9.10), o vale já entra sozinho no pagamento.

Vender no fiado (crediário)

  1. Identifique o cliente com Ins antes de finalizar.
  2. No pagamento, escolha Fiado / crediário. Aparecem o limite, o valor em aberto e o disponível do cliente.
  3. Escolha em quantas parcelas (à vista até 12x). Os vencimentos seguem as configurações (padrão: 30, 60, 90 dias…).
  4. Tecle Enter e confirme. O comprovante sai com as parcelas e um espaço para a assinatura do cliente.
Quando o gerente precisa liberarSe a compra passar do disponível ou se o cliente tiver parcela vencida (com o bloqueio ligado), abre a autorização do supervisor. Vale-troca e fiado precisam de conexão com o computador principal.

9.6 Comprovante, PDF e orçamento

Ao confirmar, aparece Venda concluída com o número e o troco. Escolha Imprimir ou PDF; Esc começa a próxima venda.

Orçamento (F8): com itens no cupom, gera um orçamento em A4 ou PDF. Não é venda e não baixa estoque.

9.7 Sangria e suprimento (F6)

Sangria é retirar dinheiro da gaveta; suprimento, colocar. A justificativa é obrigatória, o operador precisa da autorização de um gerente e sai um comprovante para assinatura. A sangria não pode passar do dinheiro esperado na gaveta.

9.8 Reimprimir e cancelar vendas (F7)

F7 lista as vendas do caixa aberto. Clique numa venda para Reimprimir (2ª via), gerar PDF ou Cancelar venda com motivo: os produtos voltam ao estoque. O operador precisa da autorização do gerente; só dá para cancelar vendas do caixa ainda aberto.

9.9 Trocar de operador (F9)

Com o cupom vazio, o próximo operador digita o usuário e o PIN. O caixa continua aberto e as vendas seguintes ficam no nome dele.

9.10 Troca, devolução, fiado e vale (F11)

Com o cupom vazio, F11 abre Outras operações. Tecle o número da opção:

1 — Troca / devolução

  1. Digite o número da venda (está no comprovante) e clique em Buscar.
  2. Em cada item, informe a quantidade a devolver (ou Tudo). Marque Avariado se o produto não pode voltar à prateleira: ele não volta ao estoque e fica registrado como perda.
  3. Escolha como devolver o dinheiro: Vale-troca (crédito para outra compra), Dinheiro (sai da gaveta deste caixa), Estorno na forma original (ex.: estorno no cartão, feito na maquininha) ou Abater do fiado (quando a venda foi no fiado).
  4. Para uma troca, deixe ligado Trocar agora por outros produtos: o vale entra sozinho como pagamento da próxima venda. Escreva o motivo.
  5. Clique em Devolver e trocar (ou Confirmar devolução). Sai o comprovante da devolução e, se for o caso, o do vale.
Como o valor é calculadoDevolve-se o que o cliente pagou pelo item: se a venda teve desconto no total, o desconto é dividido entre os itens. Cada item só pode ser devolvido até a quantidade vendida, mesmo em várias devoluções. Kits devolvem os itens ao estoque. Fora do prazo de troca (padrão 30 dias), só o gerente.

2 — Receber fiado

  1. Busque o cliente. Aparecem as parcelas em aberto, com as vencidas destacadas.
  2. Digite o valor a pagar (pode ser parcial) e escolha a forma: dinheiro, PIX, cartão etc. No dinheiro, informe o valor entregue para ver o troco.
  3. Clique em Receber. O valor abate primeiro das parcelas mais antigas e sai o comprovante de recebimento.

3 — Consultar vale-troca: digite o código do vale para ver o saldo, a validade, a origem e o histórico de uso, e imprimir a 2ª via.

9.11 Fechar o caixa (F10)

  1. Com o cupom vazio, tecle F10. Aparece o resumo: vendas, totais por forma de pagamento, recebimentos de fiado, devoluções, troco inicial, sangrias, suprimentos e o dinheiro esperado na gaveta.
  2. Conte o dinheiro e digite em Dinheiro contado. O sistema mostra se confere, tem falta ou sobra.
  3. Clique em Fechar caixa e imprimir. O relatório sai para assinatura.

Dinheiro esperado = troco inicial + suprimentos − sangrias + vendas em dinheiro + fiado recebido em dinheiro − devoluções em dinheiro

10. Entradas e saídas de estoque

As vendas do caixa já baixam o estoque sozinhas. Estas telas são para o que não passa pelo caixa.

Registrar entrada

  1. Menu Registrar entrada. Escolha Pedido recebido ou Retorno ao estoque.
  2. Bipe o produto (ou digite o nome ou SKU), informe a quantidade e confirme com o PIN.
Registro rápidoLigado, cada bipagem registra 1 unidade na hora, sem confirmar. Ideal para conferir uma caixa item por item.

Registrar saída (perdas)

Menu Registrar saída, tipo Perda / quebra / vencimento, para produtos estragados, quebrados ou vencidos.

Ajustes de inventárioOs tipos Ajuste (entrada) e Ajuste (saída), usados depois de contar o estoque, só aparecem para o administrador.

Movimentações

Menu Movimentações: histórico completo, com filtros por tipo e período. As vendas aparecem como Venda (com o nome do kit, quando o item saiu num kit), os cancelamentos como Estorno de venda cancelada, as devoluções como Devolução de venda e as notas de entrada como Pedido recebido, com o número da nota.

Mercadoria com nota fiscalPara a compra com nota do fornecedor, prefira lançar a nota de entrada (capítulo 11): ela dá entrada no estoque, atualiza o custo médio e gera as contas a pagar de uma vez só.

11. Compras: fornecedores e notas de entrada

Estoquista e administrador lançam; o gerente consulta. A nota de entrada registra a mercadoria comprada com custo: num só passo ela dá entrada no estoque, recalcula o custo médio de cada produto, lembra o código do produto no fornecedor e cria as contas a pagar das parcelas.

11.1 Fornecedores

Menu Fornecedores › Novo fornecedor: razão social, nome fantasia, CNPJ/CPF (validado), telefone, e-mail, contato, prazo de entrega e condição de pagamento. Fornecedores que vêm num XML são cadastrados sozinhos.

Clique no fornecedor para ver as notas lançadas, as contas em aberto e os produtos fornecidos, com o código no fornecedor, a conversão (ex.: caixa com 12) e o último custo. A estrela marca o fornecedor preferido do produto, sugerido nas solicitações de pedido.

11.2 Importar o XML da NF-e (o jeito mais rápido)

  1. Peça ao fornecedor o arquivo XML da nota (normalmente chega por e-mail).
  2. Menu Notas de entrada › Importar XML da NF-e e escolha o arquivo. A nota vira um rascunho com fornecedor, número, série, emissão, chave de acesso, itens, frete, descontos e as parcelas (duplicatas).
  3. Os itens já conhecidos são associados sozinhos (pelo código no fornecedor ou pelo código de barras). Os que ficam em vermelho precisam de Associar produto: escolha o produto do cadastro.
  4. Confira a conversão: quantas unidades do seu produto vêm em cada unidade da nota (ex.: nota em CX, você vende em UN, caixa com 12 → conversão 12). O sistema mostra o total em unidades e o custo por unidade, com a margem sobre o preço de venda.
  5. Confira o total calculado com o total impresso na nota e clique em Lançar nota.
Atenção à conversãoUma conversão errada distorce o estoque e o custo. Se o custo por unidade ficar muito acima do preço de venda (margem negativa em vermelho), a conversão provavelmente está errada. Na próxima nota do mesmo fornecedor, o sistema lembra a conversão.

11.3 Digitar uma nota

Sem XML (nota em papel, compra no atacarejo), use Digitar nota: escolha o fornecedor, o número, Adicionar produto em cada item (quantidade e custo unitário), frete, outras despesas e desconto. Em Parcelas a pagar, use Gerar para dividir o total. Salvar rascunho guarda para terminar depois.

11.4 O que acontece ao lançar

  • O estoque de cada produto aumenta (movimentação Pedido recebido, com o número da nota).
  • O custo médio é recalculado: (saldo × custo médio + quantidade × custo da nota) ÷ (saldo + quantidade). Com o saldo zerado ou negativo, vale o custo da nota. Frete, despesas e desconto são rateados entre os itens pelo valor.
  • O último custo e o vínculo produto–fornecedor (código e conversão) ficam gravados.
  • Cada parcela vira uma conta a pagar na categoria Compra de mercadorias (capítulo 15).
Bom saberA mesma NF-e (chave de acesso) não pode ser importada duas vezes. Rascunhos podem ser excluídos; a nota lançada não é desfeita: corrija o estoque com um ajuste e a conta em Contas a pagar. Kits não entram em nota (lance os itens).

14. Gerência: vendas e caixas

Relatório de vendas

Menu Vendas. Escolha o período (Hoje, 7 dias, 30 dias ou datas) para ver o total vendido, o número de vendas, o ticket médio, os descontos, a margem bruta (com o custo cadastrado), os valores por forma de pagamento, os produtos mais vendidos e as vendas por operador. Abaixo fica a lista de vendas: busque pelo número ou filtre as canceladas, e clique numa venda para reimprimir, gerar PDF, cancelar ou fazer Troca / devolução. Exportar CSV abre no Excel. Cancelar ou devolver?Cancelar anula a venda inteira e só vale para o caixa ainda aberto (venda lançada errado). Devolver é para o cliente que volta com o produto depois: pode ser parcial, a qualquer tempo dentro do prazo, e fica registrada com motivo.

Caixas

Menu Caixas: todos os turnos, com quem abriu e fechou, o dinheiro esperado, o contado e a diferença (falta em vermelho, sobra em amarelo). Reimprima ou baixe em PDF o relatório de qualquer fechamento.

Painel

A tela inicial mostra as vendas de hoje (gerente e administrador), os indicadores de estoque, os alertas de reposição e as últimas movimentações. No primeiro uso, um aviso de boas-vindas leva a este manual.

15. Financeiro

Gerente e administrador. O grupo Financeiro do menu reúne o que a loja tem a pagar, o que tem a receber no fiado e, juntando tudo com as vendas, o fluxo de caixa e o resultado do mês.

15.1 Contas a pagar

  1. Menu Contas a pagar › Nova conta.
  2. Informe a descrição, a categoria (aluguel, energia, salários…), o fornecedor (opcional), o valor, o vencimento e o nº do documento (boleto, fatura).
  3. Em Repetir / parcelar em, escolha Só esta vez ou quantas vezes: o valor total é dividido nas parcelas, uma a cada 30 dias. Com Conta fixa mensal ligado, o mesmo valor se repete todo mês (ex.: aluguel lançado para 12 meses).
  4. No dia do pagamento, clique em Pagar: data, valor pago (juros e multa são calculados pela diferença) e a forma de pagamento. Anexe o comprovante (PDF ou imagem), se quiser.

As abas filtram por situação (em aberto, pagas, canceladas) e por vencimento. Desfazer pagamento reabre uma conta paga por engano. As parcelas das notas de entrada chegam sozinhas, na categoria Compra de mercadorias. Em Categorias você cria categorias de despesa.

15.2 Fiado (contas a receber)

Menu Fiado (a receber): todas as parcelas das vendas no fiado. No topo, o total em aberto, o vencido (e quantos clientes estão em atraso), o que vai vencer e o que passou de 90 dias. O quadro Atraso por faixa mostra quanto está vencido há quanto tempo, e Maiores devedores ordena os clientes pelo valor.

O recebimento é feito no caixa (F11 › Receber fiado, capítulo 9.10), para o dinheiro entrar na gaveta e no fechamento. Para um acordo ou perdão de dívida, o gerente usa Cancelar o saldo desta parcela, com motivo.

15.3 Fluxo de caixa

Menu Fluxo de caixa e resultado, aba Fluxo de caixa. Mostra, para o período escolhido (padrão: hoje + 30 dias), quanto entrou e saiu (realizado) e quanto vai entrar e vai sair (previsto), com o saldo do período e o gráfico dia a dia com o saldo acumulado.

16. Excluir e recuperar produtos

  1. Abra o produto e clique em Excluir › Mover para a lixeira (o PIN é pedido).
  2. O produto some das listas, mas pode voltar com Restaurar durante o prazo (padrão: 15 dias), em Lixeira.
  3. Passado o prazo, ele é apagado definitivamente, com o histórico. Produtos que já foram vendidos no caixa nunca são apagados de vez: o histórico de vendas é preservado.
AtençãoA exclusão definitiva não pode ser desfeita.

17. Impressoras

O sistema imprime comprovante de venda (no fiado, com as parcelas e a assinatura do cliente), orçamento, sangria/suprimento, fechamento de caixa, devolução, vale-troca e recebimento de fiado. Todo comprovante traz “Documento Não Fiscal — Sem Valor Fiscal”.

Térmica USB ou serial (mais comum)

  1. Instale o driver do fabricante (Epson, Elgin, Bematech, Daruma, Tanca…) e imprima uma página de teste pelo Windows.
  2. Em Configurações, escolha Bobina 80 mm (ou 58 mm) e Impressora do Windows.
  3. Na primeira impressão, escolha a térmica, Margens: nenhuma e desmarque Cabeçalhos e rodapés. O navegador lembra a escolha.
Imprimir sem a janela de confirmaçãoCrie um atalho com o destino:
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk-printing --app=http://localhost:3000/caixa
e defina a térmica como impressora padrão do Windows. A gaveta de dinheiro ligada à impressora USB abre pelo driver (opção “abrir gaveta”).

Térmica de rede (ESC/POS)

  1. Ligue a impressora na rede e descubra o IP dela (folha de autoteste).
  2. Em Configurações, escolha Térmica de rede direta, informe o IP e a porta (normalmente 9100) e salve.
  3. Imprimir página de teste e confira os acentos. Se quiser, ligue Abrir a gaveta nas vendas em dinheiro.

Nesse modo a impressão é imediata, sem janela. Se a impressora não responder, o sistema avisa e imprime pelo navegador.

A4 e PDF

Escolha Folha A4 para impressoras comuns. O orçamento sai sempre em A4. Em qualquer comprovante, o botão PDF gera o arquivo, mesmo sem internet.

18. Backup

Aplicativo: automático no Google Drive

  1. Instale o Google Drive para computador e entre com a conta Google da loja.
  2. Feche e abra o sistema. Ele encontra a pasta Meu Drive e avisa: “Backup automático no Google Drive ativado”.

Uma cópia é salva ao abrir, a cada 4 horas e ao fechar, na pasta Meu Drive › VL Estoque - Backups. Ficam os últimos 30 dias. Sem o Drive, os backups ficam em %LOCALAPPDATA%\VLEstoque\backups.

Computador novo ou com defeito: instale o Google Drive (mesma conta) e o aplicativo. Na primeira abertura, o sistema encontra o backup e pergunta se deseja restaurar: clique em Restaurar dados.

Código-fonte: cópia manual

  1. Desligue o sistema (feche a janela preta).
  2. Copie a pasta do banco (DB_DATA_DIR) e o arquivo apps\api\.env para um pen drive ou HD externo. Sem o .env, o banco copiado não abre.
  3. Faça pelo menos uma vez por semana e guarde fora da loja.
Nunca coloque a pasta viva do banco no OneDrive ou no Google DriveA sincronização pode corromper o banco enquanto o sistema está ligado. Só os arquivos de backup podem ir para a nuvem.

19. Privacidade e LGPD

O sistema trata dados pessoais de quem o usa (nome, login, e-mail e registro das ações) e, na frente de caixa, dos clientes cadastrados. Ele ajuda a empresa a cumprir a LGPD (Lei nº 13.709/2018).

Termo de Uso e Política de Privacidade

Explica quais dados são tratados, para quê, por quanto tempo e os direitos de cada pessoa, inclusive dos clientes. Todo usuário dá ciência no primeiro acesso; o termo fica sempre em Termos e privacidade, no menu, e no link da tela de login. Se o termo mudar, o sistema pede nova leitura (e, enquanto isso, guarda as vendas offline do usuário sem perdê-las).

Para o administradorPreencha os dados da empresa e do encarregado de dados em Configurações › Empresa e privacidade. O texto do termo é um modelo: revise com um profissional jurídico.

Direitos dos usuários (funcionários)

DireitoComo exercer
Ver os próprios dadosMeu perfil › Baixar meus dados: cadastro, auditoria, operações de estoque, vendas feitas e caixas abertos.
Corrigir o e-mailMeu perfil, confirmando com a senha atual.
Corrigir o nomePedir a um administrador.
Eliminação ou anonimizaçãoO administrador desativa o usuário e usa Anonimizar dados (LGPD). As operações continuam no histórico sem identificar a pessoa.

Direitos dos clientes

O cliente pede a um gerente ou administrador, que no cadastro dele usa Exportar dados (cadastro, compras, fiado e vales-troca) ou Apagar dados (LGPD) (capítulo 8; cliente com fiado em aberto só depois de quitar). Dados pessoais de clientes só são guardados com a autorização registrada, e ofertas exigem consentimento separado.

O prazo legal para responder aos pedidos é de 15 dias.

O que o sistema faz sozinho

  • Guarda senhas e PINs de forma irreversível.
  • Guarda a senha da conta de e-mail de envio criptografada.
  • Apaga o endereço IP da auditoria depois de 12 meses e os códigos de recuperação em até 1 dia.
  • Apaga do computador do caixa a cópia dos clientes ao sair do sistema.
  • Registra na auditoria aceites do termo, exportações e anonimizações.

20. Celular e uso sem internet

Outros computadores, tablets e celulares

  1. No computador principal, descubra o IP (no cmd, rode ipconfig; ex.: 192.168.0.10).
  2. No outro aparelho, no mesmo Wi-Fi, abra http://IP:3000 (código-fonte) ou http://IP:3030 (aplicativo).
  3. No menu do navegador, toque em Instalar app (ou Adicionar à tela inicial).

Sem internet

No computador principal, o sistema funciona sem internet. Nos outros aparelhos, se a rede cair:

  • O caixa continua vendendo: o rodapé mostra “Offline — vendendo neste computador”, cada venda fica guardada no aparelho e o comprovante sai normalmente (o número aparece depois).
  • Entradas e saídas de estoque também ficam guardadas.
  • Quando a conexão volta, tudo é enviado sozinho, sem duplicar.
Precisa de conexãoAbrir e fechar o caixa, sangria e suprimento, cancelar vendas, autorização do gerente para descontos acima do limite, cadastro de cliente novo, pagamento com vale-troca ou no fiado, troca/devolução, recebimento de fiado e consulta de vale. O fechamento fica bloqueado enquanto houver vendas offline não enviadas.

21. Dúvidas frequentes

SituaçãoO que fazer
Esqueci minha senhaEsqueci minha senha no login (capítulo 3). Sem e-mail, peça ao administrador para usar Redefinir senha.
O código de recuperação não chegouConfira o spam e o e-mail em Meu perfil. O administrador testa em Configurações › Enviar e-mail de teste.
Aparece o termo de uso ao entrarO termo foi atualizado. Leia, marque “Li e concordo” e continue.
Errei o PIN e fui bloqueadoDepois de 5 PINs errados ao confirmar uma operação, aguarde 5 minutos. Se esqueceu o PIN, peça ao administrador para redefinir.
O leitor não lança o produtoTecle F1 (ou clique na busca) e bipe de novo. Teste o leitor no Bloco de Notas.
“Produto sem preço de venda”Cadastre o preço em Produtos › Editar.
“O preço de X mudou”Remova o item (Del) e bipe de novo.
A forma de pagamento está apagada no caixaEla exige cliente: identifique-o com Ins.
Desconto pede autorizaçãoPassou do limite do operador: um gerente digita usuário e PIN.
Não consigo fechar o caixaHá vendas offline pendentes: verifique a conexão e clique em “aguardando envio” no rodapé.
Diferença no fechamentoConfira sangrias, suprimentos, trocos e se alguma venda foi lançada na forma errada (relatório do caixa).
O comprovante sai cortadoNa janela de impressão, Margens: nenhuma e o papel da bobina.
Registrei uma quantidade errada no estoqueO administrador faz um ajuste com a diferença; o histórico guarda as duas operações.
O produto sumiu da listaConfira a Lixeira (administrador).
Tela antiga depois de atualizarFora do caixa, Ctrl+F5.
O cliente quer trocar um produtoNo caixa, F11 › 1, número da venda, devolva em vale-troca com “Trocar agora” ligado e bipe os produtos novos (capítulo 9.10).
O fiado pede autorização do gerenteO gerente libera com usuário e PIN, ou o cliente paga as parcelas atrasadas antes (F11 › 2).
O vale-troca não é aceitoConsulte o código (F11 › 3): o vale pode estar vencido, cancelado ou sem saldo.
A etiqueta da balança não lança o produtoConfira se a leitura está ligada em Configurações › Balança, se o número de dígitos e o modo (preço ou peso) estão iguais aos da balança e se o produto tem o Código na balança certo.
“Esta nota já foi importada”A mesma NF-e já está em Notas de entrada; abra a entrada indicada.
O custo do produto ficou estranho depois da notaProvavelmente a conversão estava errada (ex.: caixa com 12 lançada como 1). Corrija o custo no cadastro e o estoque com um ajuste.
O resultado do mês deu prejuízoConfira se os produtos têm custo cadastrado, se as despesas do mês estão corretas e a linha de perdas de estoque.
